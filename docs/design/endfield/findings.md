# 《明日方舟：终末地》界面设计语言调研

调研日期：2026 年 10 月 12 日。只调研，没有改动任何代码。本目录在 `.gitignore` 里，只存在于本机。

## 0. 读这份文档前要知道的

**标记约定**

- 【看到】：我在截图或页面里直接看到的。
- 【测得】：从网页的计算样式里读出的数值，或从本目录 PNG 截图上取的像素色值。
- 【推测】：我的判断，没有直接证据。
- 【没看到】：找了但没找到，或没能打开。

**色值的可信度分三档**

| 档 | 来源 | 可信度 |
| --- | --- | --- |
| A | 官网的计算样式（CSS） | 精确 |
| B | 官网页面的 PNG 截图取色 | 精确到渲染结果 |
| C | 游戏内截图取色 | 近似。原图经过 wiki 上传者截图、压缩，我又缩放到 1920×1080 再截了一次；半透明和渐变区域只能当参考 |

**截图是怎么来的**

内置浏览器用来打开页面、阅读、读取页面样式。但它的截图只有 800 像素宽，而且面板处于隐藏状态时经常超时或截出白屏，所以存到本目录的图是用本机 Edge 的无界面模式按 1920×1080 另截的。游戏内截图是把 wiki 或官网新闻里的图片在浏览器里打开后截屏，四周的黑边是浏览器留的，不是游戏画面。没有保存任何字体、图标、标志文件。

**最重要的三个缺口**

1. **主菜单、角色详情、背包这三类游戏内界面没有找到截图。** 下文相关小节都写了"没看到"。
2. 游戏内的动效完全没看到，只有静态图。
3. 游戏内界面的样本偏向 1.x 版本的活动和功能界面，加两张测试期的好友和名片界面，不能代表全部界面。

## 3. 字体

### 3.1 官网（A 档）

【测得】页面声明的字体名（只是名字，没有下载文件，也不能据此确认它们的授权和真实字体）：

| 名称 | 用在哪里 |
| --- | --- |
| `SansRegular` / `SansMedium` / `SansBold` / `SansBlack` | 中文。正文用 Regular，标签和按钮用 Medium，标题用 Bold |
| `Novecentosanswide`（Medium / DemiBold / Bold） | 英文大写的宽体标签：`REC`、页码 `01 02 03`、竖排的 `GAMEPLAY`、背景镂空大字 `ENDFIELD` |
| `Gilroy`（Light / Medium） | 英文小标题：`LORE`、`ARKNIGHTS: ENDFIELD`、`1 / 35` |
| `SpaceGrotesk`、`SDK_Sans` | 已加载，具体用在哪没有逐一核对 |

【测得】按 1280 宽视口换算的字号：干员名 39px；段落标题中文 24px，英文 18px；玩法标题 24px；正文 12.5 到 15px；类型标签和日期 12px；新闻详情正文 13px，文内一级标题 26px 加粗。整站用根字号按视口宽度缩放（1280 宽时根字号 8px）。

【看到】字体上的做法：

- 英文和数字一律比中文"宽"和"几何"，大量全大写。
- 中英成对出现：英文小字在上或在旁，中文粗体在下。例如 `LORE / 世界观资料`、`AIC / 集成工业知识`。
- 超大的英文字只当背景用，并且用 45° 细斜线填充成"镂空"效果，而不是实心。【测得】做法是 4px 见方的斜线渐变裁进文字形状里。

【推测】`SansRegular` 等中文字体从字形看接近思源黑体一类的黑体，但我没有办法从截图确认具体是哪一款。

### 3.2 游戏内

【看到】（`game-devcomm-03.png`、`game-devcomm-04.png`、`game-friends-list.png`、`game-profile.png`）

- 中文是黑体，中等字重，没有看到衬线体或手写体用于界面文字。
- 英文和数字是圆润的几何无衬线体，数字偏大偏细，例如等级 `58`、数量 `22 / 44 / 242`。
- 面包屑式标题以双斜线开头：`// 地区建设 /仓储节点`、`// FRIENDS /FRIENDS LIST`、`//装备方案`。
- 标题和页签下面常带一行极小的装饰性编码文字（如 `0001 0101 0 1010 101 01010 10`），小到在 1920 宽的截图里也读不清。
- 教学图里的文字全部换成了自造的几何符号（三角、方块、圆点拼成的假文字），`game-tutorial-outpost.png`、`game-tutorial-contact-panel.png` 里都是这样。

【没看到】游戏内字体的名称。

## 4. 形状与边框

【看到】

- **直角为主，胶囊为辅，几乎没有中等圆角。** 面板、标签、卡片是直角或 2 到 4px 的小圆角；按钮和搜索框则是全圆角的胶囊形。两种形状对比很强。【测得】官网：卡片圆角 4px，按钮 2 到 2.5px，分页器和圆形按钮是全圆角。
- **基本不画描边，靠色块分区。** 官网读到的边框很少，面板之间靠 `#F2F2F2`、`#E6E6E6`、`#D9D9D9` 这几档灰的色块差区分。游戏内同理，炭黑行压在灰底上，行与行之间留缝而不是画线。
- **斜切和平行四边形。** 游戏内页签右上角有斜切（`game-devcomm-03.png` 的"我转交的委托"页签）；寻访图里立绘被裁成一排倾斜的平行四边形（`game-headhunting-basic.png`）；官网干员页的黄色块是用 `clip-path` 裁出的不规则多边形。
- **L 形角标。** 面板四角常只画两个角，或者只在一角放一个小的直角符号，代替完整边框（`game-profile.png` 头像框、`game-headhunting-basic.png` 的名牌）。
- **六边形。** 名片的"Path of Glory"区是六边形蜂窝网格，教学图里的仓储量表是六边形竖条（`game-tutorial-outpost.png`）。
- **细线加端点。** 分隔线常在一端带一个小圆圈或小方块，像电路图的端子（`game-devcomm-04.png` "方案列表""套组效果"右侧的线）。
- **斜线填充。** 空白时段、禁用区域、深色按钮表面都用 45° 细斜线填充而不是纯色（`cn-site-05-calendar.png` 的空档、官网"前往游戏"按钮）。
- 【测得】官网的阴影很克制：卡片 `0 0 4px rgba(0,0,0,0.15)`，圆形按钮 `0 0 5px rgba(2,2,2,0.3)`。

## 5. 图标风格

【看到】

- 官网侧边导航的图标是**单色实心剪影**，未选中 `#D9D9D9` 左右的浅灰，选中变近黑，并且整格换成 `#E6E6E6` 底、左侧出现一条近黑竖条（`cn-site-02-operator.png`）。
- 图标造型偏方、偏块面，带切角，像工业标识牌，不是细线图标。
- 游戏内的关闭按钮是白色实心圆里一个粗 X（各界面右上角一致）；删除、置顶等操作是白色实心圆里的深色符号（`game-devcomm-04.png`）。
- 稀有度用一排**三棱形的立体小标记**表示，不是星星（`cn-site-02-operator.png`、`game-operator-file-yvonne.png`、`fzwiki-operator-si.png`）。
- 属性和职业图标放在小方块里：职业是黑底白符号，属性是彩色底白符号（寒冷是青色 `#22C6D0`）。
- 官网新闻页头部有一张**等轴测线稿插画**：白色设备、黑色描边、局部填黄，上面印着 `460ML` 这类规格文字（`cn-news-list.png`）。干员页左下角也有同类线稿。

【没看到】游戏内主菜单的功能图标全貌。

## 6. 信息的排布方式

### 6.1 官网

【看到】

- 桌面端是**左侧固定的窄竖条导航**（1920 宽时约 90px），只有图标没有文字，顶部是标志，下面依次是分段导航、一个胶囊形的工具组（用户、支付、声音）、黑色的"前往游戏"竖按钮。内容区占满其余宽度。
- 首页是一条很长的纵向滚动页，分八段：首页、干员、世界观、影像、版本日历、玩法、集成工业、公告。浅色段和深色段交替出现（干员白、世界观深蓝黑、影像黑、日历白）。
- 每段的标题是一个固定组件：一行极小的 `▼// ARKNIGHTS: ENDFIELD`，一个带斜箭头的灰色小块，英文段名，下面是中文粗体段名，旁边跟一个加号方框、两行小字、一排小方点、三色竖条。
- 键值信息用**成对的小标签**：左边深色底白字是键，右边浅灰底深色字是值，等高、紧贴。例如"阵营｜宏山科学院"。配音一栏的键换成黄底。
- 新闻列表是三列卡片，卡片下面是"类型标签 + 日期"一行，再下面是标题。
- 新闻详情页是单栏，【测得】1280 宽视口下正文栏宽约 782px，左对齐，不居中。

### 6.2 游戏内

【看到】

- 全屏界面的固定骨架：**左上角是 `//` 开头的面包屑标题，右上角是圆形关闭按钮**，关闭按钮左边放资源数量。底部是一条深色状态栏，左边放说明文字，右边放主要操作按钮（`game-devcomm-03.png`）。
- 列表是**整行的横条**，一行一条记录，行内从左到右：头像、名字、若干信息列、状态、操作。列有表头，表头是浅灰小条（`game-devcomm-03.png`）。
- 页签横排在标题下方，选中的页签变成浅色并向上凸出一点，未选中的是深色。页签两端标着切换用的键位 `Q` 和 `E`。
- 左侧竖排导航：好友界面左边是一列大图标，选中的整格填黄（`game-friends-list.png`）；活动中心左边是一列带缩略图的条目，选中的换成浅色并向右凸出（`game-event-aic-aid.png`）。
- 详情类界面是左右分栏：左边列表或预览，右边属性面板，右下角是保存按钮（`game-devcomm-04.png`）。
- 数字强调：大数字加小单位，例如 `LV.70` 里 `LV.` 很小、`70` 很大。

## 7. 标注和编号的用法

【看到】

- **双斜线 `//`** 是最常见的前缀：标题、分类、注释都用。官网 `// 新闻`、`// ENDFIELD`，游戏内 `// 活动中心`。
- **方括号 `[ ]`** 把重点词括起来：`[ REC ]`、`[ 祀 ]`、`［正式上线］`、`[Operator File]`。括号的颜色比里面的字浅。【测得】官网干员名是 `#191919`，两侧括号是 `#797979`。
- **两位或三位的补零编号**：分页 `01 02 03`；视频序号 `010 / 010 LAST`、`NEXT 02 / 010`；装备方案 `方案01`、`方案02`，并且行的左侧再用很大的半透明 `01`、`02` 做底纹。
- **`当前 / 总数`**：`1 / 35`、`1 / 6`、`1 / 4`、`27/100`、`已保存 2/20`。
- **日期用点分隔**：`2026.10.07`、`09.02`、`10.01`。版本日历里日期是黑底白字的小标签。
- **装饰性的假技术文字**：`MISSION-DEPENDENT PAYLOAD SYSTEM INTERFACES`、`EXHIBITION DEMO`、`SCPVCE DEVICE IPX3-23`、二进制串、条形码、坐标 `x: 2843 y: 749`。它们都小到接近不可读，作用是质感而不是信息。
- **十字定位标记 `+`** 散布在背景上，【测得】官网上的颜色是 `#F2F2F2`，几乎看不见（`cn-site-02-operator.png` 左上）。
- **三角箭头**：`▼` 接在 `//` 前面，`▶▶` 表示方向或进度（`game-tutorial-depot.png`、`game-profile.png` 的"Awakening Day"）。
- **排成一行的小方点**（通常 6 个），出现在段标题下面，【推测】是装饰，不对应数量。

## 8. 动效

### 8.1 官网

【测得】（来自样式表）

- 过渡时间集中在 **0.2 到 0.3 秒**，缓动是 `ease` 或 `ease-in-out`；位移类最长 0.4 到 0.5 秒。变化的属性是颜色、背景色、透明度、位移。
- 新闻列表切换时整体淡入淡出，0.3 秒，`ease-out`。
- 样式表里定义的循环动画，从名字看有：闪烁（`flashing`）、滚动提示上下移动、呼吸、跑马灯、旋转、光标闪烁。

【看到】

- 加载页：深色底，左边缘一条黄色竖条随百分比从上往下变长，旁边是黄色的大号百分比数字和 `Updating...`，右侧是白色标志和 `OVER THE FRONTIER / INTO THE FRONT`，背景是很淡的等高线（`cn-site-00-loading.png`）。
- 各段内容要滚动到位才出现。直接跳到某一段时，页面是空的，只有段标题的骨架。

【推测】各段是滚动触发的入场动画，但入场的具体形式（滑入、擦除还是淡入）我没有看到过程。

### 8.2 游戏内

【没看到】任何动效。我只看到静态截图。官方研发通讯里有三张动图，我没有逐帧看。

## 10. 官网本身的网页设计

国服 <https://endfield.hypergryph.com/> 与国际服 <https://endfield.gryphline.com/en-us> 结构相同。【看到】国际服首屏的差别：标志换成英文横排，工具组多一个入口，下载按钮换成海外平台，底部有 Cookie 提示条（`intl-site-01-home.png`）。国际服首屏以下我没有截到图，只读了文字和样式。

最接近"白底、明黄、淡等高线"的是这三处，建议优先看：

1. **新闻列表页**（`cn-news-list.png`）：白底，顶部一整条 `#FFFA00` 横幅，横幅里嵌一条白色标题条，右侧是线稿设备插画，横幅下沿是 8px 的 `#C6C6C6` 灰线。页签是"浅灰底小块 + 圆形箭头"，页签之间用 2px 竖线分隔。
2. **新闻详情页**（`cn-news-article.png`）：白底单栏，右上角是极淡的等高线，标题上方是灰色类型标签加日期，标题下一条细灰线。页面底部还有一张点阵底图，【测得】透明度只有 0.08。
3. **干员页**（`cn-site-02-operator.png`）：黄色多边形、斜线镂空大字、三色线、成对标签都在这一屏。

【测得】新闻详情正文的排版很朴素：13px、默认行高、段间距等于一个字高、链接是浏览器默认蓝。设计感集中在页头和装饰上，正文没有特殊处理。

【看到】版本日历（`cn-site-05-calendar.png`、`cn-site-05b-calendar.png`）是一张横向时间轴：顶部日期刻度，下面按"寻访、申领、活动"分行，每个条目是一条横幅，左上角挂一个青绿色的日期小标签，空档用斜线填充。

## 11. 玩家 wiki 是怎么转译这套语言的

这部分是**玩家的再创作**，不是官方设计，但可以看别人把它搬到内容型网站上时保留了什么。

**fz.wiki**（<https://www.fz.wiki/>，`fzwiki-operator-si.png`）

- 【看到】页面最顶上一条贯穿全宽的三色细线：品红、黄、青绿。
- 【看到】左侧导航每项是"中文 + 下面一行宽字距英文大写"；选中项整格变黄并带等高线底纹。
- 【看到】标签用黑底白字宽字距小块（`OPERATOR`），稀有度沿用三棱标记，信息区是"小号灰色标签在上、粗体值在下"的两列网格。
- 【测得】它的样式变量：圆角统一为 `0px`；深色主题强调色 `#D8BF00`，表面 `#181818`、`#1F1F1F`、`#232323`，边框 `#2B3136`；浅色主题表面 `#F4F5F6`，文字 `#111827`。背景有一层很淡的方格网。
- 【看到】它的黄比官方暗、偏金，不是 `#FFFA00`。

**endfield.wiki.gg**（<https://endfield.wiki.gg/wiki/User_Interface>）

- 【看到】深色主题，页签栏下面有一条品红、黄、青绿的三色细线（只在 800 像素宽的截图里看到，颜色没有取值），标题下面用一排斜线做分隔。
- 这个站后来对我的无界面截图弹出了人机验证，我没有处理验证，所以没有它的高清截图。

**B 站 wiki**（<https://wiki.biligame.com/zmd/>）

- 【看到】顶部整块黄色横幅加黑色导航条，手法比较直接。

## 14. 我的推测汇总

以下都没有直接证据，用的时候请当作假设：

1. 游戏内底色用灰而不是纯白，是为了让黄色选中态和白色胶囊按钮都能跳出来。纯白底上白色按钮无法成立。
2. 官网用"品红、黄、绿"而游戏内用"青、品红、黄"，可能只是两个团队或两个时期的差别，不一定有含义。
3. 段标题旁的小方点、二进制串、设备编号都是纯装饰。
4. 名片的青蓝色和活动中心的青绿色是可变的主题色，不属于固定的基础配色。
5. 官网中文字体接近思源黑体一类。
6. "Valley IV Menu"这类图是菜单或加载背景。
7. 官网各段是滚动触发入场的，入场形式未知。

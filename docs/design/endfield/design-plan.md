# hhikr.moe 新设计方案（终末地气质）

编写日期：2026 年 10 月 12 日。只是方案，没有改动任何代码或样式文件。

## 0. 依据与局限

- 配色、版式依据 `findings.md` 的调研和 frontend-design 的流程。
- ui-ux-pro-max 检索已用 `C:\Users\hhikr\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe`（Python 3.12.14）跑通，结果与本方案的取舍见第 8 节。
- 检索给出的"HUD / 科幻 FUI"设计系统（近黑、蓝色强调、发光）**不采用**，理由同第 8 节。
- 调研里的色值来自官网和游戏截图，是近似值。本方案的色值为网站可读性重新调过，不是复制官方色。
- 不使用任何游戏官方素材：不用它的字体文件、标志、图标、插画、截图，也不复制它的文案。

## 1. 设计方向

**网站是什么**：hhikr 的个人网站，包含文章（按发布顺序）、分类、合订本、Hot 100 算法学习区（题号 1–100）、作品下载、个人主页和管理面板。

**谁来看**：会读长文的技术向读者，偶尔是来刷算法题的人。

**首要任务**：读文章；找到某一篇（靠编号、日期、分类）；浏览题单。

**气质落点**：不是把游戏界面搬到博客上，而是取它的三个结构习惯：
1. **记录感**：每篇文章、每道题都有编号、日期、字数这类真实记录字段，用等宽小字排出来。
2. **工业式的边界**：细线、切角、网格线只标出真实的区域边界（侧栏、正文栏、可点击项），不铺满装饰。
3. **克制的黄**：黄色只表示"当前"和"可操作"，不做大面积背景。

**一句话概括**：一本编号清楚、边界分明的工程手册，正文像纸一样安静。

## 2. 保留与丢弃

| 项 | 处理 | 理由 |
| --- | --- | --- |
| `--measure` 正文栏宽、`--ease` 缓动、视图过渡 | 保留 | 与用户已确定的行为有关 |
| 日夜切换的扩散动画（3000 CSS 像素/秒、可反向） | 保留 | 用户明确要求过，不改语义 |
| LXGW WenKai GB Screen（霞鹜文楷屏幕版） | **保留，升为唯一中文字体** | 用户指定作为中文阅读体 |
| JetBrains Mono | **换为 JetBrainsNerdFont Mono** | 用户指定的等宽字体 |
| 纸张噪点背景（SVG `feTurbulence`） | 丢弃 | 与"干净的工业感"冲突，也让浅色背景发灰 |
| Instrument Serif 衬线标题 | 丢弃 | 与中文楷体的字形、与工业感都不协调，且多一个字体 |
| Inter | 丢弃 | 英文与中文楷体的混排由楷体自己的拉丁字形负责，不再需要单独的英文正文字体 |
| 系统中文字体（PingFang、微软雅黑等）作为正文 | 丢弃 | 不在本地托管，平台间字形不统一 |
| 天蓝 `--sky` 作为链接色 | 丢弃 | 与黄色、墨色体系冲突；链接改用墨色加黄色下划块 |

## 3. 配色

### 3.1 浅色主题（默认）

| 令牌 | 色值 | 用途 | 对比 |
| --- | --- | --- | --- |
| `--paper` | `#F4F4F2` | 页面底色 | — |
| `--panel` | `#FFFFFF` | 正文栏、卡片、代码区 | — |
| `--ink` | `#161616` | 正文、标题、导航文字 | 于 `--paper` 约 16.5:1，于 `--panel` 约 18:1 |
| `--ink-2` | `#5C5C5C` | 次要文字、标注、日期 | 于 `--paper` 约 6.1:1 |
| `--rule` | `#D9D9D6` | 分隔线、网格线（1px） | 装饰线 |
| `--signal` | `#FFFA00` | 当前项底色、阅读进度的标记块、选中块 | 只做填充，文字用 `--ink`（约 16:1） |
| `--tri-a / b / c` | `#FF00F0` / `#FFFA00` / `#00FFA2` | 页顶三色条 | 装饰，不含文字。`#00FFA2` 在浅底上仅约 1.2:1，只作色块，不作线 |

**浅色的禁令**：黄色不作线条或文字。`#FFFA00` 在白底上约 1.1:1，细线会消失。需要线的地方用 `--ink`。

### 3.2 深色主题

| 令牌 | 色值 | 用途 | 对比 |
| --- | --- | --- | --- |
| `--paper` | `#191919` | 页面底色（与官网近黑一致） | — |
| `--panel` | `#222222` | 正文栏、卡片 | — |
| `--ink` | `#EDEDED` | 正文、标题 | 约 14.9:1 |
| `--ink-2` | `#A3A3A3` | 次要文字、标注 | 约 6.9:1 |
| `--rule` | `#353535` | 分隔线、网格线 | 装饰线 |
| `--signal` | `#FFFA00` | 当前项、阅读进度、焦点 | 作线和作字都可以（对 `#191919` 约 15.7:1） |
| `--tri-*` | 同浅色 | 页顶三色条 | `#00FFA2` 在深底上约 13:1，可作细线 |

深色的黄色既可作填充也可作线，这是两套主题最明显的差别。

### 3.3 焦点、图标、指针

- **键盘焦点**：统一为 `outline: 2px solid currentColor; outline-offset: 2px`。浅色主题的焦点是墨色，深色是浅灰。两套主题下都要可见，不用阴影代替。
- **图标**：只用内联 SVG，不用 emoji，也不用 Nerd Font 的图标字符（它们在私用区，屏幕阅读器读不出来，也难以保证对齐）。图标库优先 Lucide（ISC 许可，复制进仓库时保留版权声明），只取用到的图标。线框图里的 `☾ ≡` 只是记号，实现时换成 SVG。
- **可点击元素**：一律 `cursor: pointer`，包括编号标签、分类块和侧栏项。

### 3.4 色的使用规则

- 正文区只用 `--ink`、`--ink-2`、`--paper`/`--panel`，不出现黄色和三色。
- 三色只在两处出现：页顶全宽细条；文章标题下方的分隔。
- 没有渐变，没有阴影（浅色主题用 1px `--rule` 边框代替）。
- 黑色用 `#161616` / `#191919`，不用 `#000` 作底色。

## 4. 字体

### 4.1 两个字体，分工明确

| 角色 | 字体 | 许可 | 用在哪里 |
| --- | --- | --- | --- |
| 中文、正文、标题、导航、按钮（含夹杂的英文单词） | **LXGW WenKai GB Screen**（霞鹜文楷屏幕版） | SIL OFL 1.1 | 所有非等宽文字 |
| 等宽标注与数字 | **JetBrainsNerdFont Mono**（JetBrains Mono 的 Nerd Font 版） | JetBrains Mono 为 OFL 1.1；Nerd Font 补丁合并了其他图标集的许可，**需核对所用构建的许可文本** | 编号、日期、字数、键值、代码、站名 |

要点：
- **楷体只有 Regular 一个字重**。标题靠字号和颜色区分层级，不用 `font-weight: bold`。浏览器合成的假粗体在楷体上很难看，不用。
- **楷体的覆盖范围**：屏幕版覆盖常用字，生僻字会回落到系统字体。`font-family` 要保留回落链，并在实现后找几篇含生僻字的文章检查。
- **等宽字体只用拉丁与常用符号子集**，中文不用它。使用 Nerd Font 版是为了它的字形（同一套等宽字形，已对齐的数字与符号），**不使用它的图标字符**。
- 由于两个字体的拉丁部分风格不同，英文和数字的显示规则是：英文单词用楷体；编号、日期、数字、路径、代码一律用等宽字体。

### 4.2 体积

- **楷体**：本机 `node_modules/lxgw-wenkai-screen-web` 中是 992 个切片、共 53.6 MB（已测量）。它已经在站点里使用，改版不增加新的字体文件，但会把它从"按页面切片加载"的现状确认下来：上线前用 Network 面板测一篇文章页和一篇 Hot 100 页的实际传输量，作为改版前后的对比。
- **等宽字体**：Latin 子集、单一字重 400，估计 50–100 KB（估计，未测量）。Nerd Font 版的体积比普通版大，需要用子集工具裁掉非拉丁与非所需符号后再量。

### 4.3 字号与行高

比例约 1.33。全部字重为 400（楷体只有这一个），层级由字号与颜色承担。

| 角色 | 字号 | 行高 | 字体 |
| --- | --- | --- | --- |
| 展示（首页站名） | 54px | 1.1 | 楷体 |
| 一级标题 | 40px | 1.25 | 楷体 |
| 页面标题 | 30px | 1.35 | 楷体 |
| 二级标题 | 22px | 1.45 | 楷体 |
| 文章正文 | 17px | 1.85 | 楷体 |
| 界面文字 | 15px | 1.6 | 楷体 |
| 等宽标注 | 13px | 1.5 | JetBrainsNerdFont Mono |

- 楷体是阅读体，中文正文的行高比黑体再加一些（1.85），这是为了让楷体的字形有呼吸。
- 正文最长行约 36–38 个汉字，即约 640px，满足"每行不超过约 80 字符"（英文按字符数计）。
- 正文左对齐，不两端对齐（中文两端对齐会留下大空隙）。
- 标题不做"单个词变色或变斜体"，整句同一颜色。

### 4.4 等宽标注的写法

- **大小写**：等宽标注用句首大写或小写，不全部大写。全大写只保留站名 `HHIKR.MOE` 作品牌标识。
- **分隔**：用竖线 `|` 或放进单元格，不用中间点 `·`。
- **内容**：每一条标注都对应一个真实字段（见第 6 节）。

## 5. 版式

### 5.1 栅格与区域

- **桌面（≥1100px）**：左侧固定侧栏 `12rem`（约 192px），内容区占剩余宽度；正文栏最大 `40rem`，居左，不居中。
- **平板（720–1099px）**：侧栏收为顶部横栏，正文栏满宽减边距。
- **手机（<720px）**：顶部 56px 横栏，导航折为 3 列 × 2 行的格子（六项），没有横向滚动。边距 16px。
- **验收宽度**：375、768、1024、1440 四个宽度都要检查。
- 网格线只在侧栏右边界和正文栏两侧画 1px `--rule` 线。它们标出的是真实的区域边界，不是背景纹理。

## 6. 结构元素与它们承载的信息

每个结构元素都必须能回答"它显示的是哪个字段"。不能回答的，删掉。

| 元素 | 承载的信息 | 来源 | 不做什么 |
| --- | --- | --- | --- |
| 文章编号 `No.003` | 发布顺序 | 发布时分配，之后不变（见第 9 节第 1 项） | 不编造编号，不用装饰性的 `01 02 03` |
| 日期 `2026.10.09` | 发布或修订日期 | 数据库 | 不用相对时间（"三天前"） |
| 字数、阅读时长 | 读者要花的时间 | 数据库已有字数字段；阅读时长由它推算 | 不写死 |
| 分类键值（成对小标签） | 分类 | 数据库 | 不用中间点串联多个属性 |
| 切角 | 可点击的入口（编号标签、分类块、当前导航项） | 样式规则 | 正文、列表行、卡片内容都是直角 |
| 网格线 | 侧栏与正文栏的边界 | 布局 | 不做背景等高线、不做十字标记 |
| 三色条 | 页面主区的开始；品牌 | 固定 | 不出现在正文区中部，不作列表装饰 |
| 阅读进度条 | 读到了哪里 | 滚动位置 | 不做循环动画 |
| 题单计数 | 题单完成度 | 从题单数据计算 | 不写死 "100 题" |

**不做的**：二进制串、坐标数字、条形码、"MISSION-DEPENDENT"之类的假技术文字、随机的装饰小方点。这些在官网里只起质感作用，对读者没有信息。

## 7. 动效

共六处动效，每一处都回应一个具体的状态变化或操作。阅读进度条不算动效，它是数据。

| # | 动效 | 触发 | 时长与缓动 | 说明 |
| --- | --- | --- | --- | --- |
| 1 | 页顶三色条扫过 | 页面载入 | 600ms，`--ease` | 全站唯一的入场时刻。扫完后内容直接出现，没有逐段淡入。 |
| 2 | 日夜扩散 | 切换主题 | 3000 CSS 像素/秒，可反向 | 保留现有实现，不改语义。 |
| 3 | 黄色选中块滑动 | 切换侧栏导航项；选中分类块 | 200ms，`--ease`，只动 `transform` | 同一个"当前"机制，导航和分类共用，不另做填充动画。 |
| 4 | 页面切换淡化 | 列表与文章之间跳转 | 200ms 交叉淡化 | 使用现有的 `@view-transition`，不叠加三色条，避免和第 1 项重复。 |
| 5 | 展开和收起 | 合订本目录、代码说明 | 200ms，`grid-template-rows` 从 0 到 1fr | 展开内容的高度变化是唯一会改变布局的动效，只用于这一种场景。 |
| 6 | 复制反馈 | 点击复制代码 | 按钮文字换为"已复制"，勾选线用 `stroke-dashoffset` 画出，约 300ms 后复原 | 同时用 `aria-live="polite"` 让屏幕阅读器读出"已复制"。 |

**去掉的几项**：分类块单独的填充动画（与第 3 项重复）；题单完成时的勾选动画（状态一次性出现，静态标记即可，不需要每次都动）；列表与文章切换时的三色条横扫（与第 1 项的入场时刻重复，会削弱它）。

**原则**：
- 只有第 1 项是"全页性"的动效，其余都局限在被操作的元素上。
- 悬停和状态切换的过渡统一在 150–250ms，只改颜色和背景，不改位置。
- 不做卡片悬停抬起，不做滚动触发的段落入场。
- 所有动效在 `prefers-reduced-motion: reduce` 下关闭：第 1 项直接显示最终状态；第 2 项保留切换结果但去掉扩散过程；第 3、5、6 项直接切换。阅读进度条仍然更新，因为它是数据。
- 动画只用 `transform` 和 `opacity`；第 5 项例外，它是唯一改变布局的动效，只用于展开收起。
- 进度条用 `transform: scaleX`，不动画布局属性。

## 8. 方案审查

### 8.1 对照 ui-ux-pro-max 的检索结果

| 检索结论 | 处理 |
| --- | --- |
| `--design-system` 给出 HUD / 科幻 FUI：`#0B0B10` 底、`#3B82F6` 蓝色强调、发光与扫描线 | **不采用**。蓝色与黄色体系冲突，发光与扫描线的可访问性风险被它自己标为 high |

## 10. 落地前的约束检查

- **CSP**：`font-src` 只允许 `'self'` 与 `data:`，所以字体必须放在站内，不能用 Google Fonts。`style-src` 已允许 `'unsafe-inline'`。`script-src` 不变，不新增脚本。
- **本地托管与许可**：楷体与 JetBrains Mono 都是 OFL 1.1，允许免费商用与自托管。**Nerd Font 版需要核对所用构建的许可文本**：它合并了其他图标集的许可，若不能确认，就用 JetBrains Mono 原版，等宽字形仍然一致。字体文件与许可证文本放进 `public/fonts/` 与 `LICENSES/`。
- **覆盖与回落**：楷体屏幕版对生僻字有回落，`font-family` 保留系统回落链。
- **不使用游戏官方素材**：字体、标志、插画、截图、文案都不取自游戏。配色是对公开截图的近似。
- **深浅两套主题**：两套令牌都定义在 `:root` 与 `:root[data-theme='dark']` 上，与现在的写法一致。
- **对比度**：正文对背景至少 6:1，远高于 WCAG AA 的 4.5:1。黄色只与 `--ink` 配对出现在文字上。焦点环按第 3.3 节。
- **检查清单**：实现后按 ui-ux-pro-max 的上线清单逐项核对（无 emoji 图标、可点击元素有指针、过渡时长、深浅两套对比度、焦点可见、减少动效、四个宽度）。
- **不改动**：文章数据、登录、评论、管理面板、Hot 100 的算法与 Java 服务。

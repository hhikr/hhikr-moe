# hhikr.moe 新设计方案（终末地气质）

编写日期：2026 年 10 月 12 日；2026 年 10 月 13 日按已实现的原型修订（见文末"修订记录"）。

本方案已经在 `redesign/endfield` 分支上实现为原型：全局的颜色、字体、形状、动效变量（`src/styles/global.css`），外壳与导航（`src/layouts/Base.astro`、`src/components/Header.astro`、`Footer.astro`），以及首页、文章页、作品页、管理页外壳和管理总览，都已按本方案重做，并由站长逐轮看过认可。其余页面按本方案铺开，进度见 `README.md`。本文描述的是**现在的决定**；与 `README.md` 有出入时，以 `README.md` 为准。

## 0. 依据与局限

- 配色、版式依据 `findings.md` 的调研和 frontend-design 的流程，之后按站长对各轮原型的意见修改。
- 早期用 ui-ux-pro-max 做过一次检索，结果与本方案的取舍见第 8 节。
- 检索给出的"HUD / 科幻 FUI"设计系统（近黑、蓝色强调、发光）**不采用**，理由同第 8 节。
- 调研里的色值来自官网和游戏截图，是近似值。本方案的色值为网站可读性重新调过，不是复制官方色。
- 不使用任何游戏官方素材：不用它的字体文件、标志、图标、插画、截图，也不复制它的文案。

## 1. 设计方向

**网站是什么**：hhikr 的个人网站，包含文章（按发布顺序）、分类、合订本、Hot 100 算法学习区（题号 1–100）、作品下载、个人主页和管理面板。

**谁来看**：会读长文的技术向读者，偶尔是来刷算法题的人；管理页只有站长自己看。

**首要任务**：读文章；找到某一篇（靠编号、日期、分类）；浏览题单；站长管理内容。

**两种调子**：

- **阅读类页面**（文章、文章列表、分类、合订本、标签、作品、关于、登录、隐私等）：安静，以读为先。白色的纸面、细线分区、等宽小字的记录字段，正文像纸一样安静。
- **展示类页面**（首页、管理页）：大胆、前卫、有工业科技感。超大粗字、实心与空心的对比、深色命令栏、圆盘与看板、机械感的动效。管理子页是干活用的表格和表单，沿用管理页的调子，但以清楚好用为先。

**气质落点**：不是把游戏界面搬到博客上，而是取它的几个结构习惯：
1. **记录感**：每篇文章、每道题都有编号、日期、字数这类真实记录字段，用等宽小字排出来。
2. **工业式的边界**：细线、切角标出真实的区域边界（侧栏、正文栏、可点击项）。允许少量质感——斜线纹 `--hatch`、背景等高线——但不得铺满，不得影响阅读。
3. **克制的黄**：黄色只表示"当前"和"可操作"，不做大面积背景。

**一句话概括**：读的地方是一本编号清楚、边界分明的工程手册；首页和管理台是这台机器的控制面板。

## 2. 保留与丢弃

| 项 | 处理 | 理由 |
| --- | --- | --- |
| `--measure` 正文栏宽、`--ease` 缓动、视图过渡 | 保留 | 与用户已确定的行为有关 |
| 日夜切换的扩散动画（3000 CSS 像素/秒、可反向） | 保留 | 用户明确要求过，不改语义 |
| LXGW WenKai GB Screen（霞鹜文楷屏幕版） | **保留，只作阅读字体** `--font-text` | 用于供人阅读的内容：文章正文、文章标题、列表里的文章名、摘要等 |
| JetBrains Mono（可变字体原版） | **保留，作界面与等宽字体** | 界面文字 `--font-ui` 的拉丁与数字部分，以及 `--font-mono` 的等宽标注和代码 |
| Noto Sans SC（思源黑体，可变字体） | **新增，作界面中文** | `--font-ui` 的中文部分：导航、按钮、标签、展示性的标题、管理页 |
| 纸张噪点背景（SVG `feTurbulence`） | 丢弃 | 与"干净的工业感"冲突，也让浅色背景发灰 |
| Instrument Serif 衬线标题 | 丢弃 | 与中文楷体的字形、与工业感都不协调 |
| Inter | 丢弃 | 界面英文由 JetBrains Mono 负责 |
| 系统中文字体（PingFang、微软雅黑等） | 丢弃 | 不在本地托管，平台间字形不统一。**站长明确否决用系统黑体作后备来凑合**，界面黑体必须自托管 |
| 天蓝 `--sky` 作为链接色 | 丢弃 | 与黄色、墨色体系冲突；链接改用墨色加黄色下划块 |

## 3. 配色

以 `src/styles/global.css` 为准，下表是它的说明。

### 3.1 浅色主题（默认）

| 令牌 | 色值 | 用途 | 对比 |
| --- | --- | --- | --- |
| `--paper` | `#F4F4F2` | 页面底色 | — |
| `--panel` | `#FFFFFF` | 正文栏、看板、代码区 | — |
| `--ink` | `#161616` | 正文、标题、导航文字 | 于 `--paper` 约 16.5:1，于 `--panel` 约 18:1 |
| `--ink-2` | `#5C5C5C` | 次要文字、标注、日期 | 于 `--paper` 约 6.1:1 |
| `--rule` | `#D9D9D6` | 分隔线（1px） | 装饰线 |
| `--signal` | `#FFFA00` | 当前项底色、选中块、需要注意的标记 | 只做填充，文字用 `--on-signal` |
| `--on-signal` | `#161616` | 黄色填充上的文字，两套主题相同 | 约 16:1 |
| `--trace` | 同 `--ink` | "这里"的线：阅读进度、目录当前项、图表的线和柱、悬停色条 | — |
| `--tag-bg` / `--tag-fg` | `--ink` / `--panel` | 编号标签的底色与字色 | — |
| `--chip` | `#E4E4E0` | 较轻的键值块、标签块、按钮的底 | — |
| `--danger` | `#B3261E` | **只用于删除一类的危险操作** | — |
| `--contour` | `--ink` 的 9% | 背景等高线 | 装饰 |
| `--hatch` | `--ink` 22% 的 45° 斜线 | 斜线纹质感 | 装饰 |
| `--tri-a / b / c` | `#FF00F0` / `#FFFA00` / `#00FFA2` | 三色条 | 装饰，不含文字。`#00FFA2` 在浅底上仅约 1.2:1，只作色块，不作线 |

**浅色的禁令**：黄色不作线条或文字。`#FFFA00` 在白底上约 1.1:1，细线会消失。需要线的地方用 `--trace`（浅色时即墨色）。

### 3.2 深色主题

| 令牌 | 色值 | 用途 | 对比 |
| --- | --- | --- | --- |
| `--paper` | `#191919` | 页面底色（与官网近黑一致） | — |
| `--panel` | `#222222` | 正文栏、看板 | — |
| `--ink` | `#EDEDED` | 正文、标题 | 约 14.9:1 |
| `--ink-2` | `#A3A3A3` | 次要文字、标注 | 约 6.9:1 |
| `--rule` | `#353535` | 分隔线 | 装饰线 |
| `--signal` | `#FFFA00` | 当前项、焦点、需要注意 | 作线和作字都可以（对 `#191919` 约 15.7:1） |
| `--trace` | 同 `--signal` | "这里"的线，深色下为黄 | — |
| `--tag-bg` / `--tag-fg` | `#3A3A3A` / `--ink` | 编号标签 | — |
| `--chip` | `#2E2E2E` | 较轻的块 | — |
| `--danger` | `#FF8A7A` | 只用于删除一类的危险操作 | — |
| `--tri-*` | 同浅色 | 三色条 | `#00FFA2` 在深底上约 13:1，可作细线 |

深色的黄色既可作填充也可作线，这是两套主题最明显的差别，由 `--trace` 统一处理：写样式时要"表示这里的线"就用 `--trace`，不要自己判断主题。

### 3.3 焦点、图标、指针

- **键盘焦点**：统一为 `outline: 2px solid currentColor; outline-offset: 2px`。切角用遮罩实现的按钮，焦点框画在块内（`outline-offset` 为负）。两套主题下都要可见，不用阴影代替。
- **图标**：只用内联 SVG（`src/components/Icon.astro`），不用 emoji，也不用字体图标。
- **可点击元素**：一律 `cursor: pointer`，包括编号标签、分类块和侧栏项。

### 3.4 色的使用规则

- 正文区只用 `--ink`、`--ink-2`、`--paper`/`--panel`；黄色只在链接下划块、`mark` 和"当前"标记上出现。
- 三色只在两处出现：页顶全宽细条；文章标题下方的分隔。
- 不用柔和的投影和装饰性渐变。切角用渐变或遮罩实现、硬边的斜线纹"影子"（如首页画框后的 `--hatch`）是允许的。
- 黑色用 `#161616` / `#191919`，不用 `#000` 作底色。
- **不要黑底配黄色大字**，尤其是浅色模式。黄色在深色底上只作小块标记（如命令栏里当前项的块、数字的角标）。
- **红色 `--danger` 只用于删除一类的危险操作**（删除按钮的擦入色、删除确认），不用于告警、状态、图表或装饰。
- **告警用 `--trace` 和黄色标记**：需要注意的数值套黄色块（`--signal` 底、`--on-signal` 字），需要注意的状态用墨色/黄色的边或小方块。

## 4. 字体

### 4.1 三个角色

| 变量 | 字体 | 许可 | 用在哪里 |
| --- | --- | --- | --- |
| `--font-ui` | **JetBrains Mono**（可变字体）配 **思源黑体 Noto Sans SC**（可变字体） | 都是 SIL OFL 1.1 | 一切界面文字：导航、按钮、标签、表单、标题性的展示字（首页字标、管理页标题）、管理页全部文字 |
| `--font-text` | **LXGW WenKai GB Screen**（霞鹜文楷屏幕版） | SIL OFL 1.1 | 只用于供人阅读的内容：文章正文、文章标题、列表里的文章名、摘要、评论正文、阅读类页面的页标题 |
| `--font-mono` | JetBrains Mono（回落到霞鹜文楷） | SIL OFL 1.1 | 等宽标注（编号、日期、字数、键值）和代码 |

要点：
- 三种字体都通过 npm 的 fontsource 包（`@fontsource-variable/jetbrains-mono`、`@fontsource-variable/noto-sans-sc`）和 `lxgw-wenkai-screen-web` 自托管，在 `global.css` 顶部 `@import`，构建时打进站内，不放在 `public/fonts/`，不用外部字体服务。
- **不用系统黑体作后备来凑合**，界面黑体必须自托管（站长明确否决）。
- **楷体只有 Regular 一个字重**。用楷体的地方不加粗，靠字号和颜色区分层级；`body` 设了 `font-synthesis: none`，避免浏览器合成假粗体。
- **界面字体是可变字体，可以用粗体**（首页字标 800，管理页标题 800，按钮 700 等）。
- **楷体的覆盖范围**：屏幕版覆盖常用字，生僻字会回落到系统字体。`--font-text` 保留回落链。

### 4.2 体积

- **楷体**：按 unicode-range 切片加载，一页只下载用到的切片。
- **思源黑体**：fontsource 的可变字体同样按 unicode-range 切片。界面文字用字集中，实际下载量应在上线前用 Network 面板量一次首页和管理页（尚未测量）。
- **JetBrains Mono**：可变字体，拉丁子集。

### 4.3 字号与行高

| 角色 | 字号 | 行高 | 字体 |
| --- | --- | --- | --- |
| 展示（首页字标） | 随容器缩放，最大约 13.5rem，字重 800 | 0.84 | `--font-ui` |
| 一级标题 `--t-h1` | 40px | 1.25 | 阅读页 `--font-text`；管理页 `--font-ui` 800 |
| 页面标题 `--t-title` | 30px | 1.35 | 同上 |
| 二级标题 `--t-h2` | 22px | 1.45 | 同上 |
| 文章正文 `--t-body` | 17px | 1.85 | `--font-text` |
| 界面文字 `--t-ui` | 15px | 1.6 | `--font-ui` |
| 等宽标注 `--t-mono` | 13px | 1.5 | `--font-mono` |

- 楷体是阅读体，中文正文的行高比黑体再加一些（1.85），这是为了让楷体的字形有呼吸。
- 正文最长行约 36–38 个汉字，即约 640px。
- 正文左对齐，不两端对齐。
- 标题不做"单个词变色或变斜体"，整句同一颜色。

### 4.4 等宽标注的写法

- **大小写**：阅读类页面的等宽标注用句首大写或小写，不全部大写。首页和管理页可以用大写的英文标签（如 `HHIKR`、`ENDMIN`）和英文副标题（`Posts`、`Overview`）。
- **分隔**：用竖线 `|`、斜线 `/` 或放进单元格（`.facts`），不用中间点 `·` 串联多个属性。
- **内容**：每一条标注都对应一个真实字段（见第 6 节）。

## 5. 版式

### 5.1 栅格与区域

- **桌面（≥1100px）**：左侧固定侧栏 `12rem`（约 192px），内容区占剩余宽度。阅读类页面的内容区是"白纸加页边"（`.spread` = `.sheet` + `.margin`）：白色的 `.sheet` 宽 `--measure` 加两侧边距，贴着侧栏；右边的 `.margin` 放目录、统计这类旁注。
- **平板（720–1099px）**：侧栏收为顶部横栏；960px 以下 `.margin` 移到 `.sheet` 下方。
- **手机（<720px）**：顶部 56px 横栏，导航折为 3 列 × 2 行的格子（六项），没有横向滚动。边距 16px。
- **验收宽度**：375、768、1024、1440 四个宽度都要检查，不得出现横向滚动。

### 5.2 首页（展示类）

以 `src/pages/index.astro` 和 `shots/home7-light.jpg` 为准。自上而下：

1. **首屏**：左栏顶部一行等宽小字（今天的日期、建站第几天、文章数、总字数，数字乱码后落定）；下面是**实心 `HHIKR` 加空心 `.MOE` 的超大界面字体字标**（字重 800、字距收紧）；再下是黄色马克笔一样的一句"hhikr 的个人网站"、一句简介和三个切角按钮。右栏是站长的线稿头像（`src/assets/avatar.png`），放在切了两个角的画框里，缩放 0.92、贴底、两侧渐隐，后面垫一块错开的斜线纹"影子"，左下压一块墨色切角铭牌写座右铭。画框和影子随指针轻微视差。
2. **近期文章滚动条**：全宽墨色带，编号黄块加标题，匀速滚动，悬停暂停。
3. **最新文章块**：白底，左侧是空心的超大编号（悬停时由左向右灌满墨色），右侧是"最新"黄标、日期字数等字段、文章标题、摘要和"阅读全文"按钮。
4. **全站索引**：标题后跟一条斜线纹带。左列是六个部分（文章、合订本、题单、分类、作品、关于）的大字行，右侧是被选中那一部分的内容；指针指向或键盘聚焦某一行即切换，选中行被墨色快门盖住、左边出现黄条。手机上改为逐段竖排。

### 5.6 管理页（展示类）

- **没有左侧列表**，也不显示网站自己的侧栏。顶部一条**深色命令栏**（两套主题下都是深色）：左边黄色切角的 `E` 徽记和 `ENDMIN`，中间八个分区（中文名配小号英文），当前分区是黄色切角块，右边是查看网站、游客视角、退出和主题切换。待处理的数目用黄色小角标。

## 6. 结构元素与它们承载的信息

阅读类页面上，每个结构元素都必须能回答"它显示的是哪个字段"。不能回答的，删掉。展示类页面（首页、管理页）可以有少量纯质感的元素（斜线纹、引线、页签），但同样不放假数据。

| 元素 | 承载的信息 | 来源 | 不做什么 |
| --- | --- | --- | --- |
| 文章编号 `No.003` | 发布顺序 | `src/lib/posts.ts` 的 `postNumbers()` 按发布顺序现算（**未完成**：原计划发布时分配并存库，见第 9 节第 1 项） | 不编造编号，不用装饰性的 `01 02 03` |
| 日期 `2026.10.09` | 发布或修订日期 | 数据库 | 不用相对时间（"三天前"） |
| 字数、阅读时长 | 读者要花的时间 | 字数由正文算出；阅读时长由它推算 | 不写死 |
| 分类键值（成对小标签 `.kv`） | 分类 | 数据库 | 不用中间点串联多个属性 |
| 切角 | 可点击的入口（编号标签、分类块、当前导航项、按钮）；管理页看板、首页画框 | 样式规则 | 阅读类页面里，正文、列表行、正文图片都是直角 |
| 背景等高线 | 质感 | `public/contour-a.svg`、`contour-b.svg` | 见下 |
| 三色条 | 页面的开始；品牌 | 固定 | 不出现在正文区中部，不作列表装饰 |
| 阅读进度条 | 读到了哪里 | 滚动位置 | 不做循环动画 |
| 题单计数 | 题单完成度 | 从题单数据计算 | 不写死 "100 题" |

**背景等高线的规则**：只在右上角和左下角各一小片（手机上只有右上角一片），墨色约 9%（`--contour`），向边缘渐隐；线条**不闭合、成束流动**，像水流（参考 `contour-reference/`）；不要一圈圈的山丘，不要点阵或网格纸。图由 `scripts/draw-contours.mjs` 生成，用作遮罩，所以颜色随主题变化。

**不做的**：二进制串、坐标数字、条形码、"MISSION-DEPENDENT"之类的假技术文字、随机的装饰小方点。这些在官网里只起质感作用，对读者没有信息。

## 7. 动效

站长要求的是更有工业科技感、更炫的动效。原则：

- **短、硬、机械**。出现的东西用 `--snap`（迅速到位后稳住），快门、擦入、灌满用 `--mech`（慢起、硬停）。时长多在 120–400ms，入场序列整体不超过一秒。
- **每个动效对应一次操作或状态变化**：指向、点击、切换页面、打开页面。不做持续循环的装饰动画。
- **全部在 `prefers-reduced-motion: reduce` 下关闭**，直接显示最终状态。阅读进度条仍然更新，因为它是数据。
- 尽量只动 `transform`、`opacity`、`clip-path`、`background-size`。
- 日夜切换的扩散动画（3000 CSS 像素/秒、可反向）保持现有行为，不改。

现有的动效：

| 动效 | 触发 | 实现 |
| --- | --- | --- |
| 页顶三色条扫过 | 一次访问的第一页 | `global.css` `.tri.top` |
| 页面切换的"快门" | 站内跳转 | `global.css` `::view-transition-new(root)`，斜切的快门 360ms `--mech` |
| 导航黄块随页面滑动 | 站内跳转 | `Header.astro` / `Endmin.astro` 的 `view-transition-name` |
| 侧栏项的引线与右移 | 指向导航项 | `Header.astro` |
| 切角按钮的黄色擦入 | 指向、聚焦按钮 | 首页 `.btn`、管理页 `.em-btn`；危险按钮擦入 `--danger` |
| 数字乱码后落定 | 页面打开、指向数字所在的块 | `src/scripts/fx.ts`，用 `data-fx-load`、`data-fx-host`、`data-fx` 挂载 |
| 列表行悬停的色条和位移 | 指向列表行 | `global.css` `.records a.record` |
| 首页的交错入场 | 打开首页 | 字标被快门推入、马克笔划过、画框从切角处揭开并有扫描线、铭牌滑入 |
| 首页的指针视差 | 指针在首屏移动 | 画框与斜线纹影子反向轻移 |
| 首页索引的快门切换 | 指向索引行 | 墨色快门、黄条、右侧内容逐行亮起 |
| 管理圆盘的组装与锁定 | 打开总览、指向一段 | 逐段装上；指向时外缘出现括弧、一道光束接到中心 |
| 管理看板通电、页签伸开 | 打开总览、指向看板 | `endmin/index.astro` |

**已知的例外，待站长决定**：首页的近期文章滚动条是持续滚动的（它承载内容，悬停即停）；管理总览外圈的虚线环在缓慢旋转，属于持续的装饰动画，与上面的原则不符。两者都在减少动效时停止。

## 8. 方案审查

### 8.1 对照 ui-ux-pro-max 的检索结果

| 检索结论 | 处理 |
| --- | --- |
| `--design-system` 给出 HUD / 科幻 FUI：`#0B0B10` 底、`#3B82F6` 蓝色强调、发光与扫描线 | **不采用**。蓝色与黄色体系冲突，发光的可访问性风险被它自己标为 high。扫描线只作为一次性的入场动效出现在首页和管理页 |
| 中文界面推荐 Noto Sans SC | **采用**，作为界面字体 `--font-ui` 的中文部分；阅读内容仍用楷体 |
| 等宽单独用时只用 400 字重、字号固定 | 等宽标注保持 400、13px；界面字体是可变字体，展示和按钮用粗体 |
| 焦点环 `outline: 2px solid currentColor; outline-offset: 2px` | 采纳（第 3.3 节） |
| 上线清单：无 emoji 图标、可点击元素有指针、150ms 左右的过渡、四个宽度、减少动效 | 采纳（第 3.3、5.1、7、10 节） |
| 对比度：正文 4.5:1 以上 | 采纳，本方案高于此标准（第 10 节） |

### 8.2 对初版套路的审查

| 通用特征 | 初版是否落入 | 现在的处理 |
| --- | --- | --- |
| 深色背景加单一亮色强调 | 初想过用深色为主 | **浅色为默认**，深色是另一套完整主题；管理页只有命令栏常驻深色 |
| 全大写的追踪标签放在标题上方 | 初版等宽标注是全大写 | 阅读类页面不用；首页和管理页可用大写英文标签 |

| 编号 `01 02 03` 装饰 | 考虑过给分类和题单加编号 | 只在文章和题单（本身有顺序）上用编号，分类不编号 |
| 卡片加阴影和圆角 | 考虑过卡片式文章列表 | 阅读类页面用表格式的行，没有卡片；**管理总览用切角看板**（没有阴影、没有圆角，且不排成规整网格） |

## 9. 已决定的事项

1. **文章编号**：原定方案 C——发布时分配编号，之后不变；草稿不分配；隐藏文章已经分配过编号的保留，取消隐藏不改号。**未完成**：现在由 `src/lib/posts.ts` 的 `postNumbers()` 按发布顺序现算，没有存库。这需要改数据库结构，不在纯界面改版的范围内，留待另行决定。
2. **字体**：三个角色——`--font-ui`（JetBrains Mono 配思源黑体，界面）、`--font-text`（霞鹜文楷，阅读）、`--font-mono`（等宽标注和代码）。都自托管。Saira、Inter、Instrument Serif 不用。（原先"楷体作为唯一中文字体"的理解已作废。）
3. **三色条**：保留，只在页顶和文章标题下两处出现。
4. **Hot 100 学习区**：只换外框、侧栏、标题、题号标签与字体；代码编辑器、动画区、Java 相关界面保持现状。理由是这些交互已经过验证，改动外观容易破坏它们。
5. **字数**：字数由正文算出，不新建字段，也不改表结构。阅读时长由字数推算，按中文约 400 字/分钟计。

## 10. 约束

- **CSP**：`font-src` 只允许 `'self'` 与 `data:`，所以字体必须在站内，不能用 Google Fonts。`style-src` 已允许 `'unsafe-inline'`。`script-src` 只允许本站和主题脚本的哈希：**可以新增本站自己的脚本模块**（如 `src/scripts/fx.ts`），不得用外部脚本或新的内联脚本。开发服务器不发这条策略，要验证须 `npm run build` 后用 `npm run preview`。
- **本地托管与许可**：楷体、JetBrains Mono、思源黑体都是 OFL 1.1，允许免费商用与自托管，字体由 npm 包提供。**思源黑体的许可证文本（OFL 1.1）还没有放进仓库，需要补上。**
- **覆盖与回落**：楷体屏幕版对生僻字有回落，`--font-text` 保留回落链；界面黑体不回落到系统黑体。
- **不使用游戏官方素材**：字体、标志、图标、插画、截图、文案都不取自游戏。配色是对公开截图的近似。
- **深浅两套主题**：两套令牌都定义在 `:root` 与 `:root[data-theme='dark']` 上。每个页面都要两套都看过。
- **对比度**：正文对背景至少 6:1，远高于 WCAG AA 的 4.5:1。黄色只与 `--on-signal` 配对出现在文字上。焦点环按第 3.3 节。
- **检查清单**：无 emoji 图标、可点击元素有指针、过渡时长、深浅两套对比度、焦点可见、减少动效、四个宽度无横向滚动。
- **不改动**：文章数据、数据库结构、接口、登录与权限逻辑、评论逻辑、Hot 100 的算法与 Java 服务。管理页**在**改版范围内，但只改界面。

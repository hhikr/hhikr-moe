# Font licences

The site serves its fonts itself, from npm packages bundled at build time.

| Font | Package | Licence |
| --- | --- | --- |
| Noto Sans SC (思源黑体), interface Chinese | `@fontsource-variable/noto-sans-sc` | SIL OFL 1.1, text in `NotoSansSC-OFL-1.1.txt` (copied unchanged from the package) |
| JetBrains Mono, interface Latin and monospace | `@fontsource-variable/jetbrains-mono` | SIL OFL 1.1, text in that package's `LICENSE` |
| LXGW WenKai GB Screen (霞鹜文楷), reading face | `lxgw-wenkai-screen-web` | The font is SIL OFL 1.1 (upstream: lxgw/LxgwWenKai-Screen); the web package itself is MIT and ships no licence file. Its OFL text is not in this repository yet. |

# 连接本机 Java 练习服务

本机服务为 Hot 100 网站提供 Java 编译运行和类型提示。程序在自己的电脑上执行，使用当前用户权限。

## 准备环境

需要 Node.js 和包含 `javac` 的 JDK。当前已用 Node.js 24、JDK 21 验证。若尚未安装，可从 [Node.js 官方下载页](https://nodejs.org/en/download)和 [Temurin 官方安装说明](https://adoptium.net/installation/)取得安装程序。

解压服务包后，在解压目录打开终端。依次执行 `node --version`、`java -version`、`javac -version`，确认终端能找到这些程序。如果已经设置 `JAVA_HOME`，服务会优先读取其中的 JDK。

## 连接网站

1. 打开网站的编程练习页，展开“如何连接本机 Java”。
2. 在解压目录执行网页显示的启动命令。命令中的网站来源必须与当前网页一致，端口必须与网页填写的端口一致。例如，正式网站使用默认端口时执行：

   ```sh
   node server.mjs --port 4337 --site https://hhikr.moe
   ```

3. 保持终端中的服务运行，在网页点击“连接本机 Java”。出现 Java 和 javac 版本后，即可编译运行并使用类型提示。
4. 结束练习时，可在网页断开连接；在服务终端按 Ctrl+C 停止服务。

若终端提示端口已被占用，选择另一个 1024 到 65535 的端口，同时修改启动命令和网页端口。若提示网站来源未获准连接，用网页当前显示的来源重新启动服务。若浏览器询问本地网络权限，需要允许当前学习网站连接本机服务。

## 输入输出与运行范围

每题初始程序包含方法签名和示例调用。完成方法后，点击“运行并比对本题示例”。需要读取控制台输入时，可在 `Main` 中使用 `Scanner`，并在网页的标准输入框填写数据。

服务只监听 `127.0.0.1`，限制程序运行时间为 5 秒、输出为 64 KB。此服务用于在自己的电脑上练习 Java，不能部署为公共代码运行服务。类型提示支持单文件中的 JDK 标准库、泛型、自定义类型及链表和树的辅助模型。
